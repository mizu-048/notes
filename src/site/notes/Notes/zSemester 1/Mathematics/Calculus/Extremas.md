- **Local** is synonymous with **relative**
- **Global** is synonymous with **Absolute**

- **Global** is the highest/lowest value of y in the whole graph
	- Does not occur at open end in a graph
	- Only one global maxima and one global minima
- **Local** is the highest value among its neighbors
	- all global extrema are also local extrema aside from the one at the each end of the curve
	- Can never occur at either end of the graph as it needs neighboring points to be relative

>[!question]- A function $f(x)$ has critical points at point(s) $c$ where $f'(c)=0$ or $f'(c)=D.N.E$
>![pg174 Ex4.1.png|center|500](/img/user/Notes/zSemester%201/Mathematics/Calculus/attachments/pg174%20Ex4.1.png)



**First derivative test**:
find f'(x), set it equal to zero and find critical points
make intervals from those critical points
Put a point from each interval in f'(x),
if sign goes from + to - its local max
if sign goes from - to + its local min

**Second Derivative Test**:
find f'(x), set it equal to zero and find critical points
put those critical points in f''(x)
if + then has local min found by putting in f(x)
if - then local max foun2d by putting in f(x)

**Concavity**:
find f''(x) and set equal to zero to find points of inflection
make intervals with the points and put a point from each interval in f''(x)
if - then it concaves down
if + then it concaves up
