# Terminologies
## Statistical terms
- **Rate:**  change / time it took for the change
- **Mean:** average: sum of all/number of all
- **Median:** ==middle value== in a set of arranged values
- **Mode:** ==value occurring== the most in a dataset





> [!question]- diff. b/w traditional and machine learning
> 
> | Aspect           | Traditional programming (rule-based)                         | Machine learning                                                                  |
> | ---------------- | ------------------------------------------------------------ | --------------------------------------------------------------------------------- |
> | Core idea        | Uses handcrafted rules written by humans.                    | Learns patterns from data to make predictions or decisions.                       |
> | Data role        | Depends mainly on explicit human-defined logic.              | Depends heavily on data quality and quantity to train models.                     |
> | Adaptability     | Fixed behavior; needs manual code changes for new scenarios. | Can adapt to new data by retraining or updating the model.                        |
> | Problem type     | Best for well-defined, deterministic tasks.                  | Best for complex, noisy, or pattern-rich tasks (e.g., images, text, forecasting). |
> | Development loop | Linear: code → test → deploy.                                | Iterative: collect data → engineer features → train → evaluate → retrain.         |
> | Interpretability | Logic and outputs are usually easy to trace and explain.     | Models, especially complex ones, can be harder to interpret and explain.          |
